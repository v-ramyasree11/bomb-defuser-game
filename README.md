
💣 Bomb Defuser Game

A simple interactive Bomb Defuser Game developed using HTML, CSS, and JavaScript.

The player must enter the correct defuser password before the countdown reaches zero to successfully defuse the bomb.

🚀 Features

- Countdown timer using JavaScript `setInterval()`.
- Keyboard interaction using `keydown` event.
- Defuse the bomb by entering the correct password.
- Stop the countdown using `clearInterval()`.
- Dynamic webpage updates using DOM manipulation.
- Displays the result when the timer reaches zero.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

 ▶️ How to Run the Project

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter the correct password before the countdown reaches zero.
5. Press Enter to defuse the bomb.
